02 / The method

How a job gets verified

We read the job board and, separately, the employer's own careers page, then compare. A job listed on both is corroborated. A job on the board but absent from the careers page is worth a question — not an accusation, because a careers page can lag. Where we cannot read the careers page at all, we say so and score nothing.

Where the data comes from

Listings are collected with Bright Data Scraper Studio collectors. Every response is archived before anything reads it, and every stored row carries the ID of the collector that produced it, so any number here traces back to a file on disk.
